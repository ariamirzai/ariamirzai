## Open-source contributions:
- [WayWiseR:](https://github.com/das-rise/WayWiseR) A ROS2-based rapid prototyping platform for validating vehicle functions in both simulation and real-world testing. Includes support for advanced computer vision, mapping and autonomous functionality.
- [WayWise:](https://github.com/das-rise/WayWise) A rapid prototyping library utilising the Qt-framework, for connected and automatic vehicles.
- [ControlTower:](https://github.com/das-rise/ControlTower) A ground control station prototype for vehicles based on PX4 and MAVLINK.
- [RCCar:](https://github.com/das-rise/RCCar) An RC car implementation based on WayWise.

Developed at [**RISE Dependable and Autonomous Systems**](https://www.ri.se/en/cybersecurity/expertise/interplay-between-safety-and-security)
